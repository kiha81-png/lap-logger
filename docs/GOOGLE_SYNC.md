# Google スプレッドシート・ドライブに保存する

走行を止めると、次の2つを自動で自分の Google アカウントに送れます。

| 送り先 | 中身 |
| --- | --- |
| スプレッドシートのシート「走行」 | 1回の走行につき1行（開始・終了、車両、コース、周回数、ベスト、走行時間、距離、最高速、ファイルへのリンク など） |
| スプレッドシートのシート「ラップ」 | 1周につき1行（タイム、最高速、セクタータイム、除外・警告 など） |
| ドライブのフォルダ「Lap Logger」 | GPS の全データ（JSON）。アプリの「読み込み」でそのまま戻せます |

- 圏外のときは「送信待ち」に入り、電波が戻ったとき（アプリを開いたとき・画面に戻ったとき・1分ごと）に送ります。
- 送り直しても行は増えません（その記録の行を置き換えます）。
- 記録中は送りません。止めてから送ります。
- 英語表示のときは、シート名が Sessions / Laps になります。

準備は最初の1回だけで、10〜15分ほどです。パソコンで行うのが楽です。

## 1. スプレッドシートを作る

1. [Google スプレッドシート](https://sheets.google.com) で、空のスプレッドシートを新しく作ります（名前は例えば「Lap Logger」）。

## 2. スクリプトを貼り付ける

1. スプレッドシートのメニューで **拡張機能 → Apps Script** を開きます。
2. 最初からある `function myFunction() {...}` を全部消して、このリポジトリの [`google/Code.gs`](../google/Code.gs) の中身を全部貼り付けます。
3. 保存（フロッピーのアイコン）を押します。

## 3. 権限を許可して、合言葉を作る

1. 上の関数の選択欄で **setup** を選び、**実行** を押します。
2. 「承認が必要です」と出たら、自分のアカウントを選びます。
   「このアプリは Google で確認されていません」と出たら、**詳細 → 〇〇（安全ではないページ）に移動** を押し、**許可** します。
   （自分で書いたスクリプトなので、この表示が出るのは普通です。許可する中身は「このスプレッドシートの編集」と「ドライブにファイルを作る」です。）
3. 下の **実行ログ** に `合言葉（アプリの設定に貼り付け）: xxxxxxxx…` と出ます。この文字列を控えます。

合言葉は、あとで確認したくなったら、Apps Script の左の歯車（プロジェクトの設定）→ **スクリプト プロパティ** の `TOKEN` で見られます。

## 4. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ** を押します。
2. 種類の選択（歯車）で **ウェブアプリ** を選びます。
3. 次のとおりにします。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. **デプロイ** を押し、表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーします。

「全員」にしないと、アプリから送れません。URL を知っていても、合言葉が合わない送信はスクリプトが断ります。

## 5. アプリに設定する

1. Lap Logger の **設定 → Googleに保存** を開きます。
2. **スクリプトのURL** と **合言葉** を貼り付けます。**名前** は空でもかまいません（シートの「名前」の列に入ります。将来ほかの人のデータも同じシートに入れるときの見分けに使います）。
3. **接続テスト** を押して「つながりました」と出れば完了です。
4. 前に記録した走行もまとめて送りたいときは、**未送信をまとめて送る** を押します。

iPhone で、Safari とホーム画面に追加したアプリの両方を使う場合は、保存場所が別なので、それぞれで設定してください。

## スクリプトを新しくしたとき

`google/Code.gs` が更新されたら、Apps Script に貼り直して保存し、**デプロイ → デプロイを管理 → 鉛筆（編集）→ バージョン：新バージョン → デプロイ** を押します。この手順なら URL は変わりません（「新しいデプロイ」を作ると URL が変わるので、アプリの設定も直してください）。

## うまくいかないとき

| 表示 | 直し方 |
| --- | --- |
| 合言葉が違います | アプリの合言葉と、スクリプト プロパティの `TOKEN` が同じか確認 |
| スクリプトの準備（setup の実行）が済んでいません | 手順 3 をやり直す |
| スクリプトの返事が読めません | URL が `/exec` で終わっているか、公開範囲が「全員」か確認 |
| 通信できませんでした | 電波が戻れば自動でやり直します。そのままで大丈夫です |
| 記録が大きすぎて送れません | 1回の走行がとても長い場合です。記録の画面から JSON で書き出して、手動でドライブに保存してください |

## 注意

- スクリプトの URL と合言葉は、他の人に教えないでください。知っている人は、あなたのスプレッドシートに書き込めます。
- URL と合言葉は、アプリの「全データをバックアップ」には入りません。機種変更のときは設定し直してください。
- 送ったあとにアプリで記録を消しても、スプレッドシートとドライブのデータは消えません。
