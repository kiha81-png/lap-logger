# 実機確認のチェックリスト

広く配る前に、iPhone と Android の両方（できれば数機種）で確認します。
結果は機種名・OSのバージョン・ブラウザとあわせて記録してください。

## 準備
- [ ] URL を開き、注意事項が表示される。同意すると閉じる
- [ ] 位置情報の許可を求められ、許可すると上の帯が「GPS 良好」になる
- [ ] 「ホーム画面に追加」ができ、アイコンと名前が正しい
- [ ] ホーム画面から開くと、ブラウザの枠なしで表示される

## オフライン
- [ ] 一度開いたあと、機内モードにしてホーム画面から開ける
- [ ] 機内モードのまま、GPS で計測できる（GPS は通信がなくても使える）

## 計測（サーキット）
- [ ] コースタブで、Google マップからコピーした座標を貼り付けられる
- [ ] 「現在地」で地点を登録できる
- [ ] 数周走った記録から、ラインの向きを自動で決められる
- [ ] 計測中、画面が消えない（「画面ON固定」と表示される）
- [ ] ライン通過でラップが区切られ、前ラップとの差が表示される
- [ ] 横画面でも表示が崩れない
- [ ] 長押しで停止でき、誤って短く押しても止まらない
- [ ] 10分以上記録しても、動作が重くならない
- [ ] バッテリーの減りと発熱（気になる程度か）

## 計測（ドラッグ・セグメント）
- [ ] 止まると「スタートできます」になり、発進で計測が始まる
- [ ] 距離と 0-100km/h（mph では 0-60mph）のタイムが出る
- [ ] セグメントで、スタートからゴールまでのタイムが出る

## 計測（フリー走行・長時間）
- [ ] コースを作らずに「フリー走行」で記録を始められる
- [ ] 距離・最高速・平均（走行中）・走行時間／停車時間が増えていく
- [ ] 「省電力表示」で黒い画面になり、「通常表示」で戻る
- [ ] 自動ロック「なし」・充電しながらで、2時間以上記録が途切れない
- [ ] 一度画面を消して戻すと「GPSが…途切れていました」と出て、記録ではその区間の線がつながっていない
- [ ] 休憩（3分以上）を挟むと、記録画面で区間が分かれる
- [ ] 半日分の記録でも、記録画面・詳細画面が重すぎない
- [ ] 1時間あたりのバッテリーの減り（充電しながら・しないで）と発熱

## G メーター
- [ ] バイク：コーナーで横G、ブレーキで前後Gが出る
- [ ] 車：ゼロ合わせができる（iPhone ではセンサーの許可が出る）
- [ ] 車：加速で点が上、ブレーキで下、右コーナーで右に動く（逆なら反転スイッチで直るか）

## 記録と解析
- [ ] 記録の一覧、ラップのカード、ラップの除外ができる
- [ ] 1周の画面で、再生・比較・地図のラベル切り替えができる
- [ ] CSV と JSON を書き出せる（共有ボタンから保存できる）

## データを守る
- [ ] 全データのバックアップを保存し、別の端末（またはブラウザのデータを消したあと）で復元できる
- [ ] アプリを閉じて開き直しても、記録が残っている
- [ ] 計測中にアプリを強制終了しても、それまでの記録が残る（最大10秒ぶん失われる）
- [ ] 新しい版を公開したとき、「新しいバージョンがあります」が出て、更新できる
- [ ] 計測中には更新の表示が出ない

## 表示
- [ ] 日本語と English を切り替えられる
- [ ] km/h と mph を切り替えられる
- [ ] 高コントラスト表示が、日なたで見やすい
- [ ] 色覚に配慮した配色に切り替えられる
